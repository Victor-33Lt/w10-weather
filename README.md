# 실시간 날씨·미세먼지 대시보드 (`26-w10-weather`)

전 세계 기상 데이터를 실시간으로 제공하는 공개 API(Open-Meteo)를 활용하여 구축한 반응형 스마트 날씨 & 미세먼지 모니터링 웹 대시보드입니다.

---

## 🌤️ 소개

본 대시보드는 사용자가 원하는 전 세계 주요 도시의 실시간 기상 상태와 대기질(미세먼지) 지표를 한눈에 파악할 수 있도록 설계된 인터랙티브 웹 애플리케이션입니다.

- **실시간 현재 날씨**: 현재 기온, 체감 온도, 상대 습도, 풍속, 강수량, 주야간(낮/밤) 상태 및 WMO 기상 코드 기반 한국어 상태 라벨과 날씨 아이콘 제공
- **대기질 지수(Air Quality)**: 미세먼지(PM10) 및 초미세먼지(PM2.5) 수치 시각화, 대한민국 환경부 4단계 기준(좋음/보통/나쁨/매우 나쁨) 컬러 뱃지 및 맞춤 행동 요령 안내
- **24시간 시간대별 기온 차트**: `weather.hourly` 데이터를 기반으로 오늘 하루 동안의 기온 추이를 미니 SVG 꺾은선 곡선과 날씨 아이콘으로 시각화
- **7일간 주간 일기예보**: 향후 7일간의 날씨 아이콘, 요일/날짜, 일일 강수 확률(%), 그리고 최저·최고 기온을 비주얼 레인지 바 형태로 표현
- **디바운스 도시 검색창**: Open-Meteo Geocoding API를 연동하여 전 세계 도시명을 검색하고 자동완성 드롭다운을 통해 원클릭 전환
- **반응형 모던 UI**: 모바일, 태블릿, 데스크톱 등 모든 디바이스 화면비에 최적화된 카드형 레이아웃

- **자체 검증(Walkthrough) 및 품질 관리**: 코드가 반영된 후 `npm run lint` 및 `npm run build`를 통해 번들링과 문법 오류를 스스로 점검하고 무결성을 확인하는 자율 에이전트의 역량을 체감했습니다.

## 🌐 데이터는 어떻게 가져오나요 (외부 API 아키텍처)

- **Open-Meteo API의 특징**:
  - 전 세계 기상청 및 관측 위성 데이터를 무료로 제공하며, 별도의 API Key 인증이 필요 없는 완전 공개(Public) API입니다.
  - 날씨 예보(`forecast`), 대기질(`air-quality`), 도시 지오코딩(`search`)으로 엔드포인트가 세분화되어 있어 필요한 데이터만 효율적으로 호출할 수 있습니다.
- **관심사 분리 (Separation of Concerns)**:
  - UI 렌더링을 담당하는 컴포넌트(`App.jsx`, `CurrentWeather.jsx` 등)와 외부 데이터 통신 로직(`src/api/weather.js`)을 철저히 분리(Decoupling)했습니다.
  - 이를 통해 API 명세가 변경되거나 엔드포인트를 교체하더라도 UI 코드 수정 없이 통신 레이어만 유지보수할 수 있는 유연성을 확보했습니다.
- **디바운스(Debounce 400ms)의 필요성**:
  - 검색창에 "Seoul"을 입력할 때 각 글자마다 API를 호출하면 5번 이상의 불필요한 네트워크 트래픽이 발생합니다.
  - 이는 API 서버에 DoS 형태의 부하를 유발하고, 서버 측 레이트 리밋에 걸려 `429 Too Many Requests`로 IP가 차단될 수 있습니다.
  - 사용자의 마지막 타이핑 이후 **400ms** 동안 추가 입력이 없을 때만 단 1회 요청을 발송하도록 디바운스를 적용하여 클라이언트-서버 간 자원을 최적화했습니다.

## 🛡️ 보안에서 확인한 것 (사이버보안과 체크포인트)

- **공개(Public) API vs 비밀(Private/Secret) API**:
  - Open-Meteo처럼 읽기 전용 기상 데이터를 제공하는 공개 API는 브라우저 클라이언트에서 직접 호출이 가능합니다.
  - 반면 결제, 고객 개인정보, 유료 과금 API처럼 비밀 키(`secret_key`)가 필요한 API는 브라우저 코드나 환경변수에 포함해서는 안 됩니다.
- **클라이언트 직접 호출의 한계와 백엔드 프록시(BFF)의 필요성**:
  - React와 같은 SPA(Single Page Application)는 빌드 후 모든 코드가 브라우저로 내려가므로, 브라우저의 F12 개발자 도구 Network 탭이나 소스 분석을 통해 API Key가 100% 탈취당합니다.
  - 탈취된 키로 인해 대규모 과금 폭탄이나 데이터 탈취 사고가 발생하므로, 반드시 **백엔드 프록시 서버(BFF, Backend For Frontend)**를 중간에 두어 민감한 키를 서버 환경변수로 은닉하고 프록시를 통해 통신해야 합니다.
- **CORS 및 Mixed Content 방어 원리**:
  - 안전한 HTTPS 사이트에서 암호화되지 않은 HTTP API를 호출할 경우, 브라우저의 보안 정책에 의해 통신이 차단되는 **Mixed Content(혼합 콘텐츠)** 위험이 발생합니다.
  - 중간자 공격(MITM)과 패킷 도청/변조를 방지하기 위해 배포 환경과 모든 외부 API 엔드포인트는 항상 강력한 TLS(HTTPS) 보안 통신 프로토콜을 유지해야 합니다.

## 🎨 커스터마이징한 부분 (나만의 개성 더하기)

기본 대시보드 스펙 외에 다음과 같은 기능들을 추가 구현하여 사용자 경험과 완성도를 극대화했습니다:

1. **옵션 A — 날씨 상태 및 주야간 기반 동적 비주얼 테마**:
   - 현재 선택된 도시의 날씨 코드와 주야간(`is_day`) 파라미터를 실시간 분석하여 대시보드 배경 그라데이션이 유기적으로 변화합니다.
   - 맑음(화사한 하늘색/앰버), 흐림(모던 슬레이트), 비(청량한 딥블루), 눈(아이시 스노우), 야간(미드나잇 인디고) 테마가 부드러운 전환 효과와 함께 적용됩니다.
2. **옵션 B — 최근 본 도시 localStorage 즐겨찾기 저장**:
   - 사용자가 검색창이나 퀵 버튼을 통해 조회한 도시를 브라우저 `localStorage`에 최대 5개까지 자동으로 보관합니다.
   - 상단에 '최근 본 도시' 칩 바가 노출되어 클릭 한 번으로 과거 조회 도시로 즉시 이동할 수 있으며, 초기화 버튼을 제공합니다.
3. **옵션 C — 일일 최대 강수 확률(%) 연동**:
   - 현재 날씨 카드에 단순 강수량(mm)뿐만 아니라 Open-Meteo 일별 예보에서 추출한 금일 최대 강수 확률(`precipitation_probability_max`) 뱃지를 함께 표기합니다.
4. **옵션 D — 섭씨(°C) ↔ 화씨(°F) 단위 변환 토글 스위치**:
   - 상단 헤더에 직관적인 단위 전환 토글 버튼을 배치하여 현재 기온, 체감 온도, 시간별 차트, 주간 예보의 모든 온도 단위를 버튼 하나로 실시간 상호 변환할 수 있습니다.
